# 上手（不需要懂编程）

从零到浏览器里看到页面，再讲清楚每天要做什么。整篇只需要会两件事：
**在文件夹里打开命令行**、**复制粘贴命令**。

---

## 它是什么

一个跑在你自己电脑上的短剧网站。它自己不抓数据，只负责把已经抓好的数据摆出来：
搜索、筛选、看详情、列链接、播本地视频、在详情页里评论。

数据从 `output/` 文件夹来。整个项目只需要装 **Python** 一样东西：
不用 MySQL，不用 Node，不用连任何外部服务。

把它想成一家图书馆：

| 角色 | 对应什么 | 干什么 |
|---|---|---|
| 采购员 | 采集工具（独立项目，不在本仓库） | 往 `output/` 放一批「书单」（`duanju_*.jsonl`），封面放 `output/covers/` |
| 书单 | `.jsonl` 文件 | 一行一部剧，写着剧名、评分、集数、标签、简介…… |
| 管理员 | 展示站 | 每次打开页面，把所有书单**当场合并**成一份总目录 |
| 借阅登记本 | `tag_edits.json`、`favorites.json`、两个 `.sqlite3` | 你在页面上做的事（改标签、点收藏、传链接、扫视频）存这里，跟书单分开 |

由此有三条结论：

1. **网站不改书单。** 你改的标签、点的收藏另存文件，优先级最高，重新导入数据也不会丢。
2. **不用重启。** 采集工具跑完，页面点一下「刷新」就是新数据。
3. **加数据 = 放文件。** 想往里加剧，按 [data.md](data.md) 的格式放一个 `.jsonl` 进
   `output/` 就行，不用改代码、不用动数据库。

## 一、装 Python（只装一次）

1. 打开 <https://www.python.org/downloads/>，下载 Python 3.10 或更新版本
2. 安装时**务必勾选** `Add python.exe to PATH`
3. 验证：按 `Win+R` 输入 `cmd` 回车，然后敲

   ```bash
   python --version
   ```

   看到 `Python 3.x.x` 就成了。

## 二、进入项目目录

把项目文件夹放到你喜欢的位置，例如 `D:\duanju-web`。之后每条命令都要先进入这个目录：

```bash
cd /d D:\duanju-web
```

（这一步是把命令行的「当前目录」切过去，之后就不用再敲了。）

## 三、要不要装依赖

| 你想做的事 | 需要装的东西 |
|---|---|
| 看数据、传链接、扫视频、改配置以外的任何事 | **什么都不用装**（Python 自带的功能就够） |
| 想跑本仓库自带的测试 | `pip install pytest` 后跑 `pytest` |

也就是说：只要 `output/` 文件夹在手（用演示数据也行，见下），你立刻就能把网站跑起来。

## 四、启动

```bash
python webctl.py start --open
```

看到类似下面几行就成功了，浏览器会自动打开：

```
已启动 pid=12345
  地址 http://127.0.0.1:8765
  数据 1649 部
  日志 O:\...\output\web.log
```

## 五、常用命令

| 命令 | 作用 |
|---|---|
| `python webctl.py start` | 后台启动（关掉命令行窗口也不会停） |
| `python webctl.py start --open` | 启动并打开浏览器 |
| `python webctl.py stop` | 停止 |
| `python webctl.py restart` | 重启（改了配置或代码后用） |
| `python webctl.py status` | 在不在跑、端口、多少部 |
| `python webctl.py log -f` | 实时看日志（出问题时用） |
| `python webctl.py open` | 只打开浏览器 |
| `python webctl.py start -f` | 前台跑，报错直接打在屏幕上 |

换端口 / 换数据目录 / 让局域网里的手机也能看：

```bash
python webctl.py start --port 9000          # 8765 被占用时
python webctl.py start --output D:\my_data  # 数据在别的文件夹
python webctl.py start --host 0.0.0.0       # 手机、平板也能访问
```

> ⚠️ `--host 0.0.0.0` 等于把站点开放给整个局域网，而且**没有登录密码**。
> 只在可信网络里用。

## 界面上有什么

### 首页

| 功能 | 在哪 | 说明 |
|---|---|---|
| 封面墙 | 页面主体 | 每页 24 / 48 / 96 部可切 |
| 搜索 | 顶部搜索框 | 剧名、标签、作者、剧 ID 都能搜 |
| 分类筛选 | 分类下拉 | 按分类收窄 |
| 标签筛选 | 标签栏 | 点词直接筛 |
| 快捷开关 | 工具栏第二行 | 收藏 / 本地视频 / ED2K / 新上架 / 原创 / 有封面 / 有详情。**点几个就是几个条件同时满足**，再点一下取消 |
| 排序 | 工具栏 | 更新、评分、集数、播放量、入库时间、变更时间 |
| 刷新数据 | 右上角「刷新」 | 重新读 `output/`，采集工具跑完点这个 |
| 分享筛选结果 | 浏览器地址栏 | 条件都写在网址里，复制粘贴就能分享 |

### 详情（点任意一张卡片）

封面、评分、集数、分类、标签、简介、作者、播放量、点赞、评论数、上线时间；
相关推荐最多 12 部；底部有「ED2K 资源」「本地视频」「评论」三个区块。

- **收藏**：简介上方的「☆ 收藏」，点过变「★ 已收藏」，卡片右上角有星标
- **改标签**：标签区直接改，改完即存
- **播放**：本地视频区块里点一行就在弹层里播，能拖进度条
- **评论**：需要先配（见 [web.md](web.md) 的评论一节）

### 右上角「ED2K 链接库」

- 上传一个 TXT（一行一条 `ed2k://` 链接），自动解析剧名和集数入库
- 自动跳过重复链接；导入记录可按批次撤销
- 剧名在短剧清单里找不到的行，带黄色「**不在短剧表**」标记
- 可按剧名 / 文件名 / HASH 搜，可单条删除，可一键导出

### 右上角「本地视频」

- 填一个**服务器上的文件夹路径**（如 `O:\video`），扫描里面的视频文件名入库
- 扫完自动刮削：把文件名对上网站里的剧，给出建议
- 只记文件名，**不会移动、改名、删除你的任何文件**
- 详情页能看到匹配到的文件并直接播放

## 每天怎么用

```bash
# 数据怎么更新取决于你的采集工具（见「往里加数据」）。拿到新的 jsonl 后：
# 1. 放进 output/（或把新的 output/ 整个覆盖过来）
# 2. 打开页面，点右上角「刷新」
```

不需要重启服务——服务会自己发现文件变了。

上传 ED2K 链接：右上角「ED2K 链接库」→ 拖入 TXT →「上传并导入」。
TXT 要求：UTF-8 或 GBK 都行，一行一条，标题行和空行会被自动忽略。

```text
ed2k://|file|某剧-01.mp4|90015171|0123456789ABCDEF0123456789ABCDEF|/
ed2k://|file|某剧-02.mp4|149337066|FEDCBA9876543210FEDCBA9876543210|/
```

扫描视频：右上角「本地视频」→ 填路径 →「扫描该目录」（扫完自动刮削）→
匹配不准的可以在预览里手工改。

## 往里加数据

**唯一正确姿势**：往 `output/` 放一个 `duanju_任意名字.jsonl`，一行一部剧。
文件名必须以 `duanju_` 开头、`.jsonl` 结尾，编码 UTF-8，**一条记录写在一整行里**。

最小可用（新建 `output/duanju_2026-11-01.jsonl`，写三行）：

```json
{"drama_id": "9001", "title": "示例：逆袭人生", "score": 8.5, "episode_total": 12, "tags": ["都市", "逆袭"], "category_name": "都市"}
{"drama_id": "9002", "title": "示例：穿越日常", "score": 7.9, "episode_total": 8, "tags": ["穿越"]}
{"drama_id": "9003", "title": "示例：反派不好当", "score": 9.1, "episode_total": 24, "is_original": true}
```

保存 → 点「刷新」→ 首页出现这三部。

**最容易踩的五条**（详细规则与全部字段见 [data.md](data.md)）：

1. `drama_id` 必须唯一，同一个 ID 会被合并成一条
2. 空值（`null` / `""` / `[]`）不会覆盖之前文件里的内容
3. `score`、`episode_total`、`views` 等字段写 `0` 等于没填
4. 一行必须是完整 JSON，写坏了只跳过那一行，其它行不受影响
5. `cover_local` 指向真实存在的图片，找不到就显示灰占位图（不报错）

ED2K 链接、本地视频、标签修改、收藏**不用手写文件**，都在页面上操作，
存在各自的文件里，重新导入数据也不会动它们。

## 常见问题

| 现象 | 怎么办 |
|---|---|
| 浏览器打不开页面 | `python webctl.py status` 看是否在跑；没跑就 `start` |
| 提示端口 8765 被占用 | `python webctl.py start --port 9000` |
| 页面一片空白、显示 0 部 | 数据目录不对：确认 `output/` 里有 `duanju_*.jsonl`，或用 `--output` 指对 |
| 放了新文件但页面没变化 | 文件名要 `duanju_` 开头、`.jsonl` 结尾；点「刷新」；还不行看 `python webctl.py log -n 50` |
| 封面都是灰色 | 图片文件不在 `output/covers/`，或 `cover_local` 指错了 |
| 评论显示「使用 GitHub 登录」 | `web/config.py` 的 `GISCUS_*` 没填全，或仓库不是 public / 没开 Discussions；改完要 `restart` |
| 视频是灰条不能播 | 那条记录是旧版用浏览器选文件夹扫进来的，根目录不是绝对路径；用「填服务器路径扫描」重新入库 |

想知道「现在到底跑的是什么、数据在哪」，一条命令就够：

```bash
python webctl.py status
```

更细的排错见 [ops.md](ops.md)。
